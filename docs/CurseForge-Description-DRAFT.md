# Smooth Classes

**Smooth Classes** turns Minecraft combat into a full RPG class system built around **branching skill trees, class specialisations, signature abilities, unique mechanics, and Ascendancy progression**.

Start through the base **Strength, Magic, and Agility** paths, then commit to one of **10 class specialisations**, each with its own playstyle, passives, active abilities, upgrades, and class mechanics.

This is not a mod where every class is just `+5% damage` in a different font.

There is damage.

There is also **blood rain, Arcane Slashes, portals, giant holy beams, dark curses, flying Hippogryphs, orbital weapons, stealth, rage, spear momentum, and a permanent list of everything your necromancer has killed**.

# Choose Your Class

Each specialisation is designed around a different combat identity rather than simply changing damage numbers.

***

## Avenger — _From Corpses We Arise_

A summoner built around the **Death List**.

Avenger is one of the strongest classes for players who love **collecting mobs and turning the world into their personal army**.

If you kill a creature and successfully record it, its **soul remains yours**. You can summon it again later, command it, keep it bound to follow you, or **unbind it** so it stays where you leave it.

That means Avenger is not just a combat class. It is also a ridiculous utility class.

Want to keep a mob around without dragging it everywhere? Unbind it.

Want to make a cursed little trading center? Kill Villagers, summon them inside your trading hall, then unbind them so they stay there.

Yes, that works.

### Core Mechanics

*   Persistent **Death List**
*   Souls collected from your kills and your summons' kills
*   Summoning through main-hand and off-hand material combinations
*   Up to **3 summon charges**
*   Bound summons follow you while they remain linked to you
*   **Unbind** summons so they stop following and stay in place
*   Recall your own summons and recover their soul and ingredients
*   **Curtain Call** — detonate one of your own summons
*   **Endless Devour** — consume weakened enemies and record them directly
*   Friendly summon faction AI

Avenger does not just raise the dead.

It inventories them.

## Rider — _Mounted Mastery_

A class centered around **speed, mounted combat, impact attacks, and aerial mobility**.

Your mount progresses alongside the class:

**Horse → Water Stride → Dread Steed → Hippogryph**

Mounted combat significantly increases your offensive potential.

### Signature Abilities

*   **Rider's Charge** — a steerable mounted impact attack
*   **War Aura** — empower yourself and your owned creatures
*   **Blazing Hooves** — leave destruction beneath your mount

Eventually, roads become optional.

***

## Lancer — _Momentum Spear_

Lancer rewards relentless spear combat.

Successful attacks build **Momentum**, increasing your spear damage while you maintain pressure.

Death removes your Momentum.

Try not to do that.

### Signature Abilities

*   **Impaling Volley** — launch copies of your held spear through multiple enemies
*   **Dragon Thrust** — charge through enemies in your aimed direction
*   **Spearstorm** — rapidly pressure an area with repeated spear attacks

***

# Class Progression

Smooth Classes uses **Puffish Skills** for its progression interface.

Your journey begins through the base paths:

**Strength • Magic • Agility**

These paths lead into the main class specialisations.

Each class then develops through its own:

*   Passive bonuses
*   Core mechanics
*   Active abilities
*   Signature skills
*   Branching upgrades

***

# Ascendancy

Completing your class progression opens the **Ascendancy Tree**.

Ascendancy is a late-game progression layer containing powerful abilities and passive upgrades that can expand your build beyond your original class identity.

Major Ascendancy thresholds further upgrade abilities:

*   **30+ Ascendancy** — enhanced forms and additional mechanics
*   **60+ Ascendancy** — final upgrades and significantly stronger effects

Ascendancy abilities include:

*   **Raining Blood**
*   **Arcane Slash**
*   **Rapidfire**
*   **Ghostwalk**
*   **Cataclysm**
*   **Righteous Hammers**
*   **Righteous Shield**
*   **Swordfall**
*   **Sword Rain**
*   **Agony**
*   **Torment**
*   **Chainbreaker**
*   and more

Most Ascendancy abilities are designed to function across different classes and builds.

Some retain thematic equipment requirements where appropriate.

For example, **Rapidfire requires a Bow or Crossbow**.

***

# Smooth Progression Integration

**Smooth Classes can be played on its own.**

It also supports **Smooth Progression**, an optional companion mod that can control the larger progression flow:

**Base Tree → Selected Class → Ascendancy**

When Smooth Progression is installed, it becomes the progression authority for unlocking later stages.

Smooth Progression is optional for Smooth Classes.

# Required Dependencies

Choose the **Fabric** or **Forge** build for **Minecraft 1.20.1**, then install
the matching loader versions of its dependencies.

| Dependency | Fabric build | Forge build |
| --- | --- | --- |
| Loader | Fabric Loader | Minecraft Forge 47 |
| API | Fabric API | Forgified Fabric API |
| Pufferfish's Skills | Fabric version | Forge version |
| Pufferfish's Attributes | Fabric version | Forge version |
| Spell Engine | Compatible Fabric version | Compatible Forge version |
| Spell Power Attributes | Compatible Fabric version | Compatible Forge version |
| Accessories | Compatible Fabric version | Compatible Forge version for 1.20.1 |

**Fabric API is required only for the Fabric build.** The Forge build uses
**Forgified Fabric API**. Sinytra Connector is not required. Other dependencies may require additional libraries of their own.

Install only one loader build of Smooth Classes. Client and server should use
matching mod versions and the same loader.
