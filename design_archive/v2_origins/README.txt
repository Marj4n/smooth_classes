Smooth Classes V1 origin scope
==============================
Active/UI-visible in V1:
- Human
- Vampire
- Mermaid
- Slime

Archived for later versions (source/data preserved here, not loaded by Puffish Skills):
- Angel
- Demon
- Doppelganger
- Homunculus
- Spriggan
- Undead
- Void
- Werewolf

To restore later, move the desired origin_* folder back to:
src/main/resources/data/smooth_classes/puffish_skills/categories/
and add its id back to data/smooth_classes/puffish_skills/config.json.
